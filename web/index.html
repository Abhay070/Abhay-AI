What it is

An assistant with a spine

Most chat assistants optimise for agreeableness — they'll tell you your plan is exciting. Praxis is built on a different instruction: respect the person, interrogate the idea. If your plan has a hole in it, the first sentence says so.

⚔

It pushes back

Agreement it didn't actually reach is a failure, not politeness. Weak assumptions get named. Better approaches get argued for.

◆

It remembers you

Durable facts persist across every conversation — and every one is visible, editable and deletable. Memory you can't audit is memory you can't trust.

⚒

It actually does things

Nine tools: exact arithmetic, web search, page reading, code execution, file analysis, memory. It computes the answer instead of predicting it.

◈

Ten ways to think

Founder mode interrogates. Teacher mode explains. Direct mode deletes every word that isn't the answer. One click, no reload, no cost.

⌂

It's genuinely yours

Runs on your machine against a local model. No account, no telemetry, no network. Your conversations live in one file you can copy.

◉

Nothing hidden

Read the exact system prompt it was given. Watch every tool call as it runs. See which memories made it into the context window.

The council

Why ask one model when you can ask three?

Every model has its own blind spots. Ask three the same hard question and they fail in different places — one invents a date, one misses the sarcasm, one gets it right. Most assistants throw that disagreement away. Praxis spends it.

⚖

The ballot is blind

The judge sees answers labelled A, B, C — never which model wrote which. It cannot vote for a brand it recognises, only for the better answer.

⚡

Race, when speed matters

All members at once, first usable answer wins. A rate-limited or sleeping backend stops being your outage.

↗

Cascade, when cost matters

Cheap model first. It escalates to the strong one only when the answer actually looks weak — most questions never need it.

◉

No silent coin flips

If the judge fails or returns nonsense, the fallback is a stated heuristic that prefers honest hedging over confident length — and it tells you that's what happened.

Verification

It checks its own homework

Ask for four sentences with no letter E and most models produce something confident and wrong. They cannot count their own letters — text is generated in tokens, several characters at a time, with no step that inspects them. So Praxis doesn't ask them to.

✕

The answer comes back

A checker reads it in microseconds: 'e' appears 15×, 's' appears 16×, and three descriptions are 7 words, not 8.

↻

It gets sent back

The model is handed the exact defects — not "try again", but which letters, which items, which counts. Repairing a named fault is easy. Counting was the impossible part.

✓

Or it admits it

After a bounded number of attempts it says what it couldn't meet. An undisclosed violation dressed up as compliance is the worse failure.

A mode is a behavioural overlay, not a different model — so switching is instant and costs nothing. The core identity holds throughout; the mode sharpens it for the work in front of you.

Tools

It computes instead of guessing

Language models are unreliable at arithmetic — not because they're bad at maths, but because they're predicting plausible digits rather than calculating. Praxis calls a tool instead, and shows you every call as it happens.

a real turn, as it actually runs 
you › how many pixels in a 4K frame, and is that 4× 1080p?

  ∑ calculate   3840*2160                       ✓
  ∑ calculate   (3840*2160)/(1920*1080)         ✓

praxis › 8,294,400 pixels. And yes — exactly 4×, because 4K
doubles both dimensions rather than one.

Memory

It knows you — and shows its work

Praxis stores keyed facts, not transcripts. "Prefers Rust for systems work" is memory. "Asked about lifetimes on Tuesday" is not. Every fact records where it came from and how often it's been used.

◆

Six categories

fact · preference · project · goal · decision · skill. Deliberately small — a taxonomy nobody can remember is one nobody uses correctly.

◉

Explainable recall

Relevance is keyword overlap plus usage, not embeddings. At personal scale it's about as accurate and has one decisive advantage: you can tell why a memory surfaced.

✎

Fully editable

Open the memory panel, edit any fact in place, delete one or all. A current instruction always overrides a remembered preference.

⌂

Local, always

One SQLite file on your disk. Nothing uploaded, nothing shared, nothing leaving the machine unless you point it at a hosted model.

# 3 · restart. that's the whole setup.
python server.py                  ✓ ready
