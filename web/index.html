What it is

An assistant with a spine

Most chat assistants optimise for agreeableness. Praxis is built on a different instruction: respect the user, interrogate the idea. If your plan has a hole in it, the first sentence says so.

⚔

It pushes back

Agreement it did not actually reach is a failure, not politeness. Weak assumptions get named. Better approaches get argued for.

◆

It remembers

Durable facts about you persist across every conversation — and every one is visible, editable and deletable. Memory you cannot audit is memory you cannot trust.

⚒

It acts

Nine tools: exact arithmetic, web search, page fetching, code execution, file reading, memory writes. It computes rather than predicting the answer.

◈

Ten modes

Founder mode interrogates. Teacher mode explains. Direct mode removes every word that isn't the answer. One click, no reload.

⌂

It's yours

Runs on your machine against a local model. No account, no telemetry, no network. Your conversations sit in a SQLite file you can back up by copying it.

◉

Nothing hidden

Read the exact system prompt it was given, watch every tool call as it runs, see which memories entered the context window.

Operating modes

Ten ways to think

A mode is a behavioural overlay, not a different model — so switching is instant and costs nothing. The core identity holds throughout; the mode sharpens it for the work in front of you.

◈StandardBalanced. Adapts to whatever you bring.

Tools

It computes instead of guessing

Language models are unreliable at arithmetic — not because they're bad at maths, but because they're predicting plausible digits rather than calculating. Praxis calls a tool instead, and shows you every call as it happens.

∑

calculate

Exact arithmetic via a parsed AST — never eval(), which on model output is a remote-code-execution hole.

⌕

web_search

Four interchangeable backends: DuckDuckGo free, Brave, Tavily, or your own SearXNG.

⇲

web_fetch

Reads a page as clean text. Scripts and styling stripped, truncated sensibly.

▶

run_python

Real execution in a subprocess with a hard timeout. Off by default, and the docs say plainly what the isolation does and doesn't give you.

▤

read_file

Full text of anything you upload or drag in. Code, CSV, Markdown, PDF.

◆

remember · recall · forget

The model decides what is worth keeping. You decide what it keeps.

a turn, as it actually runs 
you › how many pixels in a 4K frame, and is that 4× 1080p?

  ∑ calculate  3840*2160                        ✓
  ∑ calculate  (3840*2160)/(1920*1080)          ✓

praxis › 8,294,400 pixels. And yes — exactly 4×, since
4K doubles both dimensions rather than one.

Memory

It knows you, and you can see exactly what it knows

Praxis stores keyed facts, not transcripts. "Prefers Rust for systems work" is memory. "Asked about lifetimes on Tuesday" is not. Every fact records where it came from and how often it has been used.

◆

Six categories

fact · preference · project · goal · decision · skill. Small on purpose — a taxonomy nobody can remember is one nobody uses correctly.

◉

Explainable recall

Relevance is keyword overlap plus usage, not embeddings. At personal scale it's about as accurate and has one decisive advantage: you can tell why a memory surfaced.

✎

Fully editable

Open the memory panel, edit any fact in place, delete one or all. A current instruction always overrides a remembered preference.

⌂

Local, always

One SQLite file on your disk. Nothing is uploaded, nothing is shared, nothing leaves the machine unless you point it at a hosted model.

Get started

Running in about two minutes

Clone it and it works immediately on the demo backend — no key, no model, no account. Then point it at something intelligent.

terminal 
# 1. install and run — works out of the box
pip install -r requirements.txt
python server.py                  # → localhost:8000

# 2. give it a real brain (free, local, offline)
curl -fsSL https://ollama.com/install.sh | sh
ollama pull llama3.2
echo "PROVIDER=ollama" > .env

# 3. restart. that's it.
python server.py
